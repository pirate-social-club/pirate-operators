request bytes without dispatch. Only after that transaction commits may the
journey commit uncertainty with a copy of that command. Deliberate dispatch
rereads the same original. Recovery from either side of the two-database

never reconstructed under a new UUID. No local signature or canonical proof is
invented by this metadata protocol.

when the current same-target journey points elsewhere. The separate local path

hold access to new actions and cannot be replayed by selecting another route.

a new target only after fresh exact safely canonical prior review confirmation
and an atomic no-active-command check. Scoped receipt acknowledgement follows
confirmed submission readback and never erases another outstanding command.

decoding. Private page/preview consumers are synchronously masked and late
