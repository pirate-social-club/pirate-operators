Reviewed the nine workflow files at PR head `f0feb0783d25797ecbd38a9cfa61602fbc6febb0`. Seven are byte-identical to base `afff5da0a6059d3a6ddf212233f60532a10d2220`. The two additional files run final acceptance and the standalone installation diagnostic. This audit covers the workflow shell blocks, their failure propagation and the associated check results.

## Shell selection

No workflow, job or step in the nine files sets a `shell` key. Three jobs specify a default working directory. These are all the `defaults` blocks found in the reviewed tree. GitHub invokes an unspecified Linux shell as `bash -e` when Bash is available. Its explicit `shell: bash` invocation adds `-o pipefail`. Each pipeline below enables `pipefail` in its own shell.
